## How each playbook is built
- **Snapshot and recent deals** carry source links. Where search found nothing dated in the last 12 months, the file says so and tells you where to look. Nothing is filled in by guesswork.
- **10 likely questions**: unless a public interview report is cited, every question is "typical for this role type (unverified for this firm)". The only firm-sourced question is Gera's Q10.
- **Red flags** use the AmbitionBox data in `hunt/roles.json` (rating, review count, WLB, work policy).
- Before any interview, spend 10 minutes updating the "Recent deals" section with news from the last month.
